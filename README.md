## ⚡ 30 秒上手

> **不需要任何 API Key** —— 默认走免费数据源（akshare / 腾讯财经）；有 Wind 终端时才用得上 Key。

```bash
# 0 · 获取代码
git clone https://github.com/shengjidaguai-china/Financial_Modeling.git
cd Financial_Modeling

# 1 · 装依赖（核心四件套：akshare / pandas / numpy / pyarrow，无需任何 Key）
python -m venv .venv
.venv\Scripts\activate           # Linux / macOS: source .venv/bin/activate
pip install -r requirements.txt
pip install lightgbm             # 训练/评估必需（可选依赖）

# 2 · 训练（采集 → 特征 → 训练 → 评估，自动完成）
python main.py train             # 首次约 2~6 分钟（采集占大头，需联网）

# 3 · 预测 / 起服务
python main.py predict 300308.SZ --horizon all    # A 股 · 全部周期
python main.py predict AAPL.US  --horizon all    # 美股 · 与 A 股同口径
python main.py serve                              # REST API → http://localhost:8800
```

> 💡 **可选依赖**按需安装（不装则对应命令明确报错，不静默跳过）：
> `lightgbm`（训练/评估）· `optuna`（`tune` 超参搜索）· `hmmlearn`（`regime` 状态分层）·
> `mapie`（`conformal-interval`）· `fdnpy`（美股期权，需 `FDN_API_KEY`）。详见 [`requirements.txt`](requirements.txt)。

## 🌐 数据源与多市场能力

支持 **A 股 / 美股 / 国内期货 / 海外期货 / 外汇 / 美股期权 / 美股基本面** 七类资产。
采用混合架构——股票/期货/基本面复用 akshare 免费档（零新依赖），仅期权引入 fdnpy。

### 代码后缀约定

`split_symbol` 按后缀自动路由，collector 无需改代码：

| 后缀 | 市场 | 数据源 | 示例 | 费用 |
|---|---|---|---|---|
| `.SH` / `.SZ` | A 股 / ETF | akshare / 腾讯 | `600519.SH` | 免费 |
| `.SHF` / `.DCE` / `.CZC` / `.INE` | 国内期货 | akshare | `RB.SHF` | 免费 |
| `.FXCM` | 外汇 | akshare（新浪通道） | `USDCNH.FXCM` | 免费 |
| `.US` | **美股股票** | akshare `stock_us_daily` | `AAPL.US` | 免费 |
| `.GLB` | **海外期货** | akshare `futures_foreign_hist` | `CL.GLB` | 免费 |

### 数据源优先级链（逐级降级，永不崩溃）

```text
Wind MCP (P0)  ──▶  akshare (P1)  ──▶  腾讯财经 (P1)  ──▶  模拟数据 (P6)
   需 WIND_API_KEY     免费 · 覆盖期货/外汇/美股   免费 · 前复权      仅链路验证 · 不落盘
```

> akshare 是免费档中**唯一覆盖国内期货、外汇与美股**的通道；未安装时静默跳过。
> 模拟数据**绝不写入缓存**——不会污染真实历史（数据卫生硬约束）。

### 美股期权（fdnpy，需 API Key）

akshare 无美股期权，故引入 [fdnpy](https://github.com/financialdatanet/fdnpy)（FinancialData.Net SDK）
补齐期权链 / 价格 / Greeks。需 Standard 订阅档 Key；未配置时**优雅降级**（返回 None，不阻断主链路）。

```bash
pip install fdnpy
export FDN_API_KEY=your_key          # Windows: set FDN_API_KEY=your_key
```

```python
from src.data.fdn_client import FdnClient
fdn = FdnClient(config)
chain  = fdn.fetch_option_chain("MSFT")                  # 期权链（contract/expiration/strike/put_call）
prices = fdn.fetch_option_prices("MSFT260123C00455000")  # 合约日K（date/open/high/low/close/volume）
greeks = fdn.fetch_option_greeks("MSFT260123C00455000")  # Greeks（delta/gamma/theta/vega/rho）
```

### 美股基本面（akshare 免费档，无需 Key）

```python
from src.data.akshare_client import AkshareClient
fin = AkshareClient(config).fetch_us_fundamentals("AAPL.US")   # 财务报表（非 OHLCV，作额外因子源）
```

> 期权为**非 OHLCV 资产类别**，不进 collector 日K优先级链，由调用方按需独立取数。
> TradingView 未接入：其无官方数据 API，第三方 tvDatafeed 逆向私有 WebSocket 违反 ToS 且无期权支持。

## 📊 核心结论（如实读，包括不好看的部分）

> **最新本地复跑**（2026-09-29 · 真实行情免费档 · 目标泄漏已修复）
> 数据口径：38 只标的（26 A股/ETF + 10 期货 + 2 外汇），2020-01-01 起，时序三段切分。

| 模型周期 | 准确率 | AUC | 评级 |
|:---|:---:|:---:|:---|
| 🟦 短期 5d | 49.19% | 0.5143 | 接近随机 |
| 🟨 中期 10d | 47.70% | 0.5391 | 低于随机 |
| 🟪 长期 20d | 46.99% | 0.5435 | 低于随机 |

> ⚠️ 召回率 ≈ 1.0 = **退化解**（近乎恒定方向输出），准确率不携带信息；判断区分度看 AUC。

### 🔻 最硬的结论：这套信号**没有可用的决策增量**

九轮独立排查（2026-09-17 ~ 09-19，详见 [`cairn/`](cairn/)）用「相对全池等权的净超额」作记分板，结论一致：

- **净超额三周期全部为负或不显著**（5d t −2.12 / 10d t −2.79 / 20d t −2.27）；随机抽同数量标的，5d 有 7.5% 概率不亚于信号
- **状态分层无正向状态**；**八个特征子集无一转正**；**风险预警退路也堵死**（朴素波动基线 IC 0.69~0.75，模型增量仅 0.03~0.09）
- 唯一方向为正的线索（rank 截面排序 OOS +12.7pp）**DSR 0.099 仍不足** ⇒ 维持 `report_only`

> ✅ **定位结论**：本项目的正确用法是「**可审计的信号研究工具 / 只读观测源**」，**不是**「高胜率赚钱机器」。
> 所有信号出口均带 `position_role=observer`、`affects_gate=false`，**不产出仓位、不改门禁**。

### 工程纪律（可核验）

| 纪律 | 实现 | 怎么验 |
|:---|:---|:---|
| **防目标泄漏** | `get_feature_columns` 强制排除 `target_*` 列 | `tests/test_label_leak_guard.py` |
| **特征契约对齐** | 训练端持久化 `feature_cols`，推理端按名称+顺序校验，缺列 fail-close | `tests/test_predictor_feature_alignment.py` |
| **模拟数据不落盘** | 兜底数据只用于链路验证，不写缓存 | `src/data/collector.py` |
| **门禁 fail-close** | 门禁不可用 / 数据缺失 / 未达标 → 一律不放行，信号保持只读 | `src/trading/gate.py` |
| **无前视评估** | 时序切分 + CPCV 净化交叉验证（purge/embargo） | `python main.py overfit-audit` |

## 🖥️ 接口与交付形态

### REST API（FastAPI · 默认端口 8800）

| 方法 | 端点 | 说明 |
|:---:|:---|:---|
| `GET` | `/health` | 健康检查 |
| `GET` | `/api/v1/predict/{symbol}` | 单只预测（`?horizon=`） |
| `POST` | `/api/v1/predict/batch` | 批量预测 |
| `GET` | `/api/v1/portfolio/summary` | 组合级摘要 |
| `GET` | **`/api/v1/decision/feed`** | **决策源契约**：净看涨概率 / 综合分 / 采纳建议 |
| `GET` | `/api/v1/audit/report` | 审计报告 / 命中率统计 |

### 决策源契约（`decision-feed/1`）

把「方向字符串 + 概率」的换算**收到生产方一侧**，下游不必自己重复实现。结构性纪律：
`position_role = observer`、`affects_gate = false`、`advisory_only = true` —— **只读：不产出仓位、不改门禁**。

```bash
curl "http://localhost:8800/api/v1/decision/feed?symbols=300308.SZ,510300.SH"
python main.py decision-feed --stdout    # 离线导出同一份契约
```

### TradingView 交付（`tv-export`）

```bash
python main.py tv-export                    # 全池 → signals/<symbol>.png + pine/trendcast/<symbol>.json
python main.py tv-export --symbols 510300.SH
```

> **像素即契约**：卡片上的每个数值与决策源契约逐字段相等（守卫 `tests/test_tv_export.py`）。

## ⚙️ 配置要点

默认加载 `configs/config_pro.yaml`（存在时优先），可用 `--config <path>` 覆盖。

```yaml
data:
  source: ["wind", "akshare", "tencent", "simulation"]   # 按序回退
  start_date: "2020-01-01"
  markets:
    stock:     {enabled: true}    # 26 只 A股/ETF
    futures:   {enabled: true}    # 10 只国内期货主连（RB.SHF / CU.SHF / SC.INE …）
    forex:     {enabled: true}    # 2 只外汇（USDCNH.FXCM / USDCNY.FXCM）
    us_stock:   {enabled: false}  # 美股日K（AAPL.US / MSFT.US / NVDA.US / TSLA.US / AMZN.US）
    us_futures: {enabled: false}  # 海外期货（CL.GLB / GC.GLB / SI.GLB / ZSD.GLB / ZC.GLB）

model:
  type: "lightgbm"
  factors: {enabled: true, families: [trend, momentum, volatility, volume, reversal, sentiment, macro]}

training:
  adaptive_learning: {enabled: true, drift_threshold: 0.05, auto_retrain: true}
```

> 改标的池：直接编辑 `configs/config_pro.yaml` 的 `markets.*.symbols`，无需改代码。
> 美股期权不进 markets 配置（非 OHLCV），由 `FdnClient` 独立取数。

## ⚠️ 已知限制

- **信号无正向 edge**（最硬结论）：净超额三周期为负或不显著，状态分层无正向状态，消融无子集转正
- **风险预警退路同样不成立**：朴素 trailing-vol 基线 IC 0.69~0.75，模型增量仅 0.03~0.09
- **模型存在退化倾向**：召回率 ≈ 1.0（近乎恒定方向输出）⇒ 准确率不携带信息
- **样本长度不足**：MinTRL 2173~8382 天 ≫ 现有 1569 天；DSR 0.08~0.24
- **数据源依赖**：美股股票/海外期货/基本面走 akshare 免费档；美股期权需 fdnpy + `FDN_API_KEY`（缺 Key 优雅降级）；Wind 需终端与 Key（可选）
- TimesFM / Kronos 路径尚未接入主推理链路（后者为第三方源码快照，仅实验底座）
